# Installation Guide This guide provides detailed step-by-step instructions to install **DataMonitor** and set up the required dependencies. --- ## Tested Environments: - **Linux:** Ubuntu 20.04 LTS, Python 3.8+ - **Windows:** Windows 10, Python 3.11.5+ --- ## Required Packages To use **DataMonitor**, ensure you have the following Python packages installed. It is recommended to use the versions listed in the `requirements.txt` file. ### Install Required Python Packages Individually: Run the following commands to install the required packages: ```bash pip install numpy==1.22.4 pip install pandas==1.5.0 pip install scikit-learn==1.2.0 pip install matplotlib==3.5.3 pip install seaborn==0.12.1 pip install jupyterlab==3.5.3 pip install statsmodels==0.13.2 pip install scipy==1.9.3 pip install PyYAML==6.0 ``` ### Install All Dependencies at Once: You can install all dependencies listed in requirements.txt using: ```bash pip install -r requirements.txt ``` --- ## Installation Using Anaconda Anaconda simplifies package management and virtual environment setup. Steps: 1. Install Anaconda: Download Anaconda from [Anaconda Distribution](https://www.anaconda.com/products/distribution) and install it. 2. Create a New Environment: Open a terminal or Anaconda Prompt and run: ```bash conda create -n datamonitor python=3.8 conda activate datamonitor ``` 3. Install Dependencies: Install required packages: ```bash pip install -r requirements.txt ``` 4. Run Jupyter Notebooks: Use the following command to start JupyterLab: ```bash jupyter lab ``` --- ## Direct Installation You can also directly install DataMonitor and its dependencies without using Anaconda. 1. Install prerequisites: ```bash sudo apt-get update sudo apt-get install python3-pip python3-venv ``` 2. Clone the repository: ```bash git clone https://github.com/DIDSR/DataMonitor.git cd DataMonitor ``` 3. Create a virtual environment and activate it: ```bash python3 -m venv datamonitor-env source datamonitor-env/bin/activate ``` 4. Install dependencies: ```bash pip install -r requirements.txt ``` --- ## Installation from Source You can also build and install DataMonitor from source. 1. Clone the repository: ```bash git clone https://github.com/DIDSR/DataMonitor.git cd DataMonitor ``` 2. After downloading the source code, you can install it using the following command: ```bash python setup.py install ```
