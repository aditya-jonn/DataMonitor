# Data (Input/Output) Examples

Examples of the input and output files can be found in the `/data/` directory.

Below are the input and output examples for each module:

---

## **Feature Extraction Module**
- **Input**: 
  - Raw image files (`.DICOM`, `.TIFF`, `.JPEG`) or processed feature embeddings.
  - **Link to Example Data File**: [InputDataExample](./data/input_feature_extraction)
  - **Link to Jupyter Notebook Example**: [FeatureExtractionNotebook](./notebooks/feature_extraction.ipynb)

- **Output**: 
  - Extracted features in `.csv` or `.npy` format.
  - **Link to Example Output File**: [ExtractedFeatures](./data/output_feature_extraction)

---

## **OOD Metric Generation Module**
- **Input**: 
  - Feature embeddings generated by the **Feature Extraction Module**.
  - **Link to Example Data File**: [FeatureEmbeddings](./data/input_ood_metrics)
  - **Link to Jupyter Notebook Example**: [OODMetricGenerationNotebook](./notebooks/ood_metric_generation.ipynb)

- **Output**: 
  - Metric scores indicating the similarity or distance between distributions, stored in `.csv` format.
  - **Link to Example Output File**: [MetricScores](./data/output_ood_metrics)

---

## **SPC Module**
- **Input**: 
  - Metric scores generated by the **OOD Metric Generation Module**.
  - Statistical Process Control parameters (e.g., thresholds).
  - **Link to Example Data File**: [SPCInputMetrics](./data/input_spc)
  - **Link to Jupyter Notebook Example**: [SPCNotebook](./notebooks/spc_module.ipynb)

- **Output**: 
  - SPC charts highlighting drift or anomalies.
  - Flags raised for detected deviations.
  - **Link to Example Output File**: [SPCResults](./data/output_spc)
  - **Example SPC Chart**:
    ![SPC Output Example](./images/spc_output_example.png)

---

## **End-to-End Pipeline**
- **Input**: 
  - A batch of test images (`.DICOM`, `.TIFF`, `.JPEG`).
  - Reference dataset features for comparison.
  - **Link to Example Input Data Batch**: [TestImages](./data/input_pipeline)

- **Output**: 
  - Identified OOD instances and flagged drift.
  - Visualizations of data shifts and SPC results.
  - **Link to Example Output Data**: [PipelineResults](./data/output_pipeline)
  - **Example Output Visualization**:
    ![Pipeline Visualization Example](./images/pipeline_output_example.png)
